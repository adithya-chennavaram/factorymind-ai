# FactoryMind Model Trust Lab — evidence and demo

## What is new

A new Streamlit multipage **Model Trust Lab** (`pages/1_Model_Trust_Lab.py`) provides a read-only analysis of blocked out-of-fold predictions, inspection-budget comparisons, a label-concealed Green-Light Challenge, and an optional AMD-hosted bounded evidence hearing. The main app, training code and existing AMD investigation are unchanged.

## How to run

1. Copy this patch over the project root; it adds new files only.
2. Keep the existing `artifacts/green_challenge_scored.csv` generated by `python -m scripts.evaluate_green_challenge` and `artifacts/metrics.json`.
3. Run `python -m pytest -q`.
4. Keep the AMD environment variables and team API key set **privately in the same Terminal** as before.
5. Run `python -m streamlit run app.py --server.port 8501`.
6. Use Streamlit's navigation to open **Model Trust Lab**. The optional AMD button makes a live API call and uses team quota; the rest of the page is completely offline.

## Real, curated post-hoc case examples

- **Cycle 2053:** blocked OOF predicted Optimal (uncalibrated score 0.8855); actual Small lag; 0/50 simulated gain scenarios switched the predicted class. Stable but wrong.
- **Cycle 2184:** blocked OOF predicted Optimal (0.8435); actual Small lag; 0/50 switches. Stable but wrong.
- **Cycle 507:** blocked OOF predicted Optimal (0.4160); actual Small lag; 26/50 switches. Fragile and wrong.
- **Cycle 638:** blocked OOF predicted Optimal (0.3725); actual Small lag; 26/50 switches. Fragile and wrong.

These examples were chosen knowing the outcomes. Do not extrapolate their behavior to unseen factory data. The main app serves a **different random-holdout model**, so its per-case predictions must not be conflated with the cross-validated predictions on this page.

## Boundaries

- No operator action or equipment control is triggered.
- Do not equate a stable prediction with a correct one, or simulated sensor gains with real failure progression.
- No reliable improvement from combined stress ranking has been shown.
- AMD is used for bounded evidence **selection and human inspection focus**. Actual numbers are rendered from the source CSV; the LLM never receives the ground-truth label.
- Do not describe an audit-log hash as immutable without a verified append-only store/signatures.

## Recommended demo story

1. Show 98.01% random holdout accuracy versus 82.86% blocked accuracy.
2. Show 260 erroneous green predictions, with confidence-only catching 136 when reviewing 266/1,344 predicted-green cases (20% per fold).
3. Run the **Stable but wrong** example (cycle 2053): there were no classification switches despite the misclassification. Reveal the actual label after the audience has made a trust decision.
4. Contrast with the **Fragile and wrong** example (cycle 507): 26 of 50 simulated gain cases changed the class.
5. Ask the AMD-hosted model to prioritize bounded, verifiable evidence and independent checks. If the provider is unavailable, leave the demo honest; do not label a fallback as AMD output.
6. Close with: 'FactoryMind doesn't promise every challenge catches every failure. It shows what the model can and cannot reliably establish before an operator trusts it.'
